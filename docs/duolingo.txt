# Typographies

Feather Bold : Feather Bold is the typeface we use for headlines, when we want to shout out and get noticed. It's bespoke to Duolingo, so no one else can use it. But let's make sure that we use it nicely!

DIN Next Rounded : Din Next Rounded is our typeface for longer sections of text. We also use it in our marketing if the headline is 10 words or longer

Substitute font, Nunito : In circumstances in which you do not have access to the brand fonts, use the substitute font Nunito. Nunito is a free Google font already available in Google Docs, Sheets, and Slides. It shares visual similarities with DIN Next Rounded with rounded caps and friendly characteristics
